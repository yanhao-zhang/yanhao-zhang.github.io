# Yanhao Zhang

Personal homepage of Yanhao Zhang. Research interests include MLLM, AIGC, foundation models, AI agents, and AgentOS.

Website: [yanhao-zhang.github.io](https://yanhao-zhang.github.io/)

The site contains a short biography, news, selected recent publications, honors, and academic service.

## Local preview

Install the dependencies in `Gemfile`, then run `bundle exec jekyll serve` and open <http://127.0.0.1:4000/>.
